PV Signal Calculator - installable app (PWA) package

Files: index.html, manifest.webmanifest, sw.js, icons/

1. Upload ALL files (keeping the icons folder) to any HTTPS host
   (GitHub Pages, Netlify, Cloudflare Pages, your own site).
2. Open the https:// link on a phone:
   - Android Chrome: menu > Install app / Add to Home screen
   - iPhone Safari: Share > Add to Home Screen
3. The app then opens full-screen and works offline.

Android APK / Play Store: go to https://www.pwabuilder.com , enter your
hosted https:// link and choose Android > Download package.
